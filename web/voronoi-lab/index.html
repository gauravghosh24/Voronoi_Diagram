i

What this model represents

The browser reproduces the project’s nearest-site rules on a small grid. Brute Force is exact. JFA uses eight neighbors per pass plus one extra jump-1 correction, so it can still miss a nearest site. The proposed implementation fills per-site frames using floor(sqrt(dx² + dy²) + 0.5); tied radius bands are resolved by exact squared distance, then the lower site index. Its animated radius slices are a teaching view: the actual Taichi fill kernel processes site–offset pairs in parallel, and pixel reduction happens afterward. This is a browser simulation, not a CPU/GPU benchmark or the paper’s exact MDCS procedure.
