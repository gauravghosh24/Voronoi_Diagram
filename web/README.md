# Voronoi Algorithm Lab on Render

Render serves the files in `web/voronoi-lab` as a static site. The repository-root `render.yaml` defines the service. No runtime server or build dependencies are required.

For local preview, serve `web/voronoi-lab` with any static HTTP server.

The browser simulator demonstrates Brute Force, the project's JFA schedule, and the project's radius-band method. It is an educational model, not a CPU/GPU runtime benchmark or the original paper's exact MDCS procedure.
